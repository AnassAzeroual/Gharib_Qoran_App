# AGENTS.md — Standing Rules

Rules every agent working in this repository MUST follow.

## 1. Keep the project context file always up to date

- `quran-app/AI Agent Help context project.md` is the master context a new agent needs to onboard.
- **Whenever the project changes** (code, scripts, commands, versioning, signing, assets, structure, tooling, workflows, or any quirk/decision), UPDATE this file in the same pass — add, modify, or delete sections as reality changes.
- If a section no longer reflects the project, DELETE or rewrite it; do not leave stale content.
- **NEVER delete the file itself.**
